## Getting Started Playbook

Use the portable NVIDIA or AMD package that matches the compute GPU, not necessarily the adapter connected to the monitor. Extract the full build to its own writable directory and start **veyra_qml_ui.exe**. Keep the PS5 awake on the same local network and turn on **Enable Remote Play** in **Settings → System → Remote Play**. Use Ethernet for the console if discovery or motion proves unreliable over Wi-Fi.

Open **Home → PS5**, select the discovered console or enter its local IP, then use **Get Account ID** to open the third-party lookup named by the project. Enter the matching numeric or Base64 account ID, not your PlayStation password, and supply the eight-digit code shown by the console's **Pair Device** or **Link Device** screen. Connect and confirm sound and controller response with effects disabled before opening **Professional → List → Frame generation**. For a known steady 30 fps source on a 60 Hz display, try a supported 2× option by itself and bypass it if motion starts stuttering or controls feel late.

## Troubleshooting Common Issues

Install issues? If the executable is missing or fails before Home opens, check that you extracted the complete GPU-specific archive rather than the source bundle.  
Performance problems? Use the source readout with frame generation off, then check GPU stage times after re-enabling it.  
Edition differences? No app unlock is needed; for rejected registration, confirm the account ID and request a fresh console code.  
Compatibility? If detection fails, put both devices on the same non-guest network and try the console's current local IP.  
Update failures? Launch the new portable build without old runtime files and follow the matching release's user-data migration notes if needed.
